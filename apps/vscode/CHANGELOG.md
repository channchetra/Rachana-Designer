# Changelog

## 1.0.0

Initial release.

- Visual, drag-and-drop editor for HTML, Markdown and Astro.
- Byte-preserving saves: patches are applied to the original source text.
- Full styling panel, DOM tree, source pane, design tokens, animations,
  layout presets, grid builder, snapshots, screenshots and WordPress export.
- No account, no sign-in, no licence tier — every feature is unlocked.
